Relmap — how the chain connects

🔗 Centre → State → District → Block → GP → Ward

Six tiers. Top two are elected to Parliament/Assembly; bottom four mix elected representatives with civil-service counterparts. Every citizen sits inside one chain that touches all six.

Reading it: Every Bihari citizen has, simultaneously, a Ward Member, Mukhiya, Pramukh, ZP member, MLA, MLC, MP (LS), MP (RS) and a CM — nine elected layers, plus the appointed DM/SP/BDO chain. This catalogue names them where it can, links the live registers where the count is too large.

DM/SP postings rotate frequently (Bihar averaged 13 DM transfers in the Dec-2025 reshuffle alone). Rather than embed a snapshot that goes stale in weeks, this table links each district's official site, which carries the current officer on its home page.

Recommendation

Hybrid is the only honest answer. A single HTML can credibly capture the top ~150 named officials (CM, Cabinet, all MPs, key bureaucrats, constitutional-body heads, ZP & ULB chairs of the largest cities). For everything below district level, the catalogue should hand off to lgdirectory.gov.in, sec.bihar.gov.in, egramswaraj.gov.in and each district's .nic.in site — these are the authoritative, live-updated registers. Embedding 1.5 lakh names in static HTML would be stale within days, impossible to verify by hand, and duplicates what the government already publishes.

Suggested next iterations

  1. Per-district pages — 38 small HTMLs, one per district, each listing DM/SP/SDO/BDO/Mukhiya counts and linking the district site & ZP chair.
  2. Build script — fetch live data from lgdirectory.gov.in & SEC nightly, regenerate this HTML automatically. Freshness + structure.
  3. "Who represents my pincode?" — a single search bar resolving pincode → Ward Member → Mukhiya → BDO → MLA → MP → Union Minister.
  4. Replicate for other states — same template, swap data. Bihar has ~1.46 L reps; UP has ~8 L. The hybrid rule scales.
