Relmap — how the chain connects

🔗 Centre → State → District → Block → GP → Ward

Six tiers. Top two are elected to Parliament/Assembly; bottom four mix elected representatives with civil-service counterparts. Every citizen sits inside one chain that touches all six.

Reading it: Every Telanganite citizen has, simultaneously, a Ward Member, Mukhiya, Pramukh, ZP member, MLA, MLC, MP (LS), MP (RS) and a CM — nine elected layers, plus the appointed DM/SP/BDO chain. This catalogue names them where it can, links the live registers where the count is too large.

🛠 How this catalogue works

A visual walkthrough of the 7-tier governance pyramid this site catalogues, and the rule deciding what gets named inline vs linked to a live register.

① The 7-tier pyramid

Telangana's governance stack runs from 1 Union Cabinet at the apex down to ~1.14 lakh Ward Members at the base. Each tier roughly multiplies the count below it by 10×–100×.

Cards in every lens use the same colour key as the pyramid: 🟢 named inline · 🟠 linked to live register · 🔴 too volatile to embed.

③ How a query flows through the catalogue

The promise: every named person on this page comes with a link back to the official source that minted them. Every layer this page does not name comes with a link to the authoritative live register that does. Transparency = traceability, not bulk.
